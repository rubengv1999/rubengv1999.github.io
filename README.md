# Rubén González Villanueva — Portfolio

A responsive portfolio for Rubén González Villanueva, software engineer, professor, and AI/ML researcher. It is built with plain HTML and CSS; no package manager, build step, or external runtime dependencies are required.

Live site: <https://rubengv1999.github.io/>

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Deployment

GitHub Pages publishes the static site from the root of the `main` branch. The free `github.io` address is used; a paid custom domain is not required.

The sitemap and crawler instructions are available at `/sitemap.xml` and `/robots.txt`.
